# Hi, I'm Osahon 👋

Senior software engineer with **18+ years** building production systems across
**fintech, payments, iGaming/betting, healthcare, government and telecoms** —
12 of them hands-on in Java. I've led engineering teams as a technical lead and
still do my best work close to the code.

### What I build
- **Money-moving backends** — wallets, ledgers, payouts, refunds and reconciliation,
  with the idempotency and locking that keep balances right under concurrency
- **Betting and gaming platforms** — raffles, jackpots, P2P betting, settlement logic
- **Integrations** — payment providers, SMS gateways and third-party core systems
- **Full-stack products** — Spring Boot APIs behind React/Next.js front ends

### Selected work
- **Provably fair raffle platform** *(personal project)* — Java 21, Spring Boot,
  PostgreSQL, Flyway. Winners are derived from a SecureRandom seed via HMAC-SHA256,
  so any player can independently verify a draw. Wallet, refund-on-cancel and payout
  paths are tested against real Postgres rather than an in-memory stand-in.
- **P2P betting exchange** *(prototype)* — players bet against each
  other rather than the house; sports markets and social wagers.
- **Community association platform** — membership, levies, billing and project
  tracking for a residents' association in Lagos.

### How I work
- Tests first on anything that touches money; integration tests against real databases
- AI coding tools every day — paired with written specs, adversarial review and
  verification loops so the output is checked, not trusted
- Security-minded: I run pre-production security audits for client platforms

### Stack
`Java` `Spring Boot` `TypeScript` `React` `Next.js` `PostgreSQL` `MySQL` `MongoDB`
`Docker` `AWS` `JUnit` `Vitest`

*Most of my work lives in private repositories. Happy to walk through any of it.*
